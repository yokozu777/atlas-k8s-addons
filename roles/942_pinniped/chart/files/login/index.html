Pinniped kubeconfig

This cluster uses Pinniped (Supervisor + Concierge) with Keycloak as the identity provider. Download the kubeconfig, install the matching CLI, then kubectl will open a browser login.

Download {{ .Values.loginUi.clusterDomain }}.yaml

1. Install the Pinniped CLI ({{ .Values.pinnipedVersion }})

Put the binary on your PATH as pinniped. The kubeconfig exec plugin calls pinniped by name (not a controller path). Without that binary on PATH, kubectl cannot log in.

OS / archAsset
Linux amd64 pinniped-cli-linux-amd64
Linux arm64 pinniped-cli-linux-arm64
macOS amd64 pinniped-cli-darwin-amd64
macOS arm64 pinniped-cli-darwin-arm64
Windows amd64 pinniped-cli-windows-amd64.exe

Linux / macOS:

chmod +x pinniped-cli-*
sudo mv pinniped-cli-* /usr/local/bin/pinniped
pinniped version

2. Use the kubeconfig

export KUBECONFIG=./{{ .Values.loginUi.clusterDomain }}.yaml
kubectl get ns

A browser window opens against Keycloak. Sign in with a user in group k8s-admins (maps to cluster-admin). Concierge issues a short-lived client certificate.

Break-glass

Controller admin kubeconfig remains admin.conf. Kubelogin OIDC remains *.oidc (client kubernetes). Do not commit downloaded kubeconfig files.
